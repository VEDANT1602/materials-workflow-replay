# Frozen record-linkage experiment

Dated 21 November 2026, before case selection, model inference or scoring. This file is locally time-stamped and hashed. No public registration is claimed.

## Question and estimands
Can an auditor recover a particular archived evaluation and its undisplayed area under the ROC curve (AUC) from a partial export? Catalog source: OpenML evaluation listings for tasks 3, 6, 12, 23, 28, 31, 37 and 44. Use the first 384 listings separately for predictive accuracy, Cohen’s kappa and AUC, join by task and run ID and retain finite legal scalar values. Use the original scalar AUC from the archive, as recorded. No new classifier will be trained. Report measured scores from historical workflows, the run selection rule and restricted catalog size. The unit of comparison is a task, not a run pair treated as an independent replication.

For every historical record compute the set of candidate runs compatible with its dataset and whole-percentage accuracy, with and without kappa rounded to the nearest 0.1. Round ties to even with decimal arithmetic from the archive. Report unique-run rate, rates for which compatible AUCs span at most 0.02 (midrange within 0.01 of every compatible AUC), and median compatible AUC span. Examining rounding sensitivity to 0.1 percentage point accuracy and 0.01 kappa is secondary. Do not assert population precision. Present every task and the range of leave-one-task-out macro-average effects. If a metric endpoint or task is unavailable document attempts and any amendment before inference.

## Blinded forced choice
From each task form up to 16 disjoint pairs of runs with identical reported whole-percentage accuracy, using a pre-fixed pseudorandom order (NumPy PCG64 seed 21112026). Repeated scores, procedures and workflows are permitted. Select one original per pair, randomized under within-task balance: half A, half B; enforce even pair count. Process identical candidate lists twice in separate prompts: original rounded accuracy only vs additionally retained original kappa rounded to 0.1. Show both candidate accuracies and candidate kappas rounded in the same manner in BOTH conditions. Restrict the prompt to anonymous numerical fields and the two candidate letters. Omit original IDs, dataset names, AUCs and keys. Measure both exact source selection and absolute archived AUC error. A leftmost-matching rule, a constant A rule and uniform random choice in expectation are baselines. No candidate can be selected by a held-out AUC. Apply the same cases to each model.

Use two separately released, instruction-tuned model families: Qwen2.5-0.5B-Instruct and SmolLM2-135M-Instruct. Use Q4_K_M GGUF weights, local CPU decoding with each model’s ChatML system/user/assistant format, no tools, demonstrations or model-specific task tuning. Choose whichever of the single assistant-start letters A or B has the larger next-token logit, ties A. Report the actual package and weight hashes. This is a 2-choice catalog linkage task using executable historical run scores, not independent classifier reproduction or unrestricted code generation. If weights cannot run, report exact technical limits and freeze any replacement before the first trial. No human participant, no inference about human performance. No later prompts are selected to improve measured scores. Preserve the exact prompt states, file digest for the separate answer key, unrounded results, per-task summaries and unsuccessful configurations.
